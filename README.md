# Tarana Bansal: financial modelling, valuation and advisory portfolio

Live site (after you publish): https://taranapgdm27g-png.github.io/financial-advisory/

Built for the Senior Business Analyst application at Preferred Square.

## Publish in 3 minutes (GitHub Pages)
1. On GitHub, create a new public repository named **financial-advisory**.
2. Upload every file in this folder to the repository root (drag and drop the contents, not the folder itself).
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. After a minute the site is live at the link above.

## What is here
- index.html: main page (role fit table, selected work, Deal Studio, Orvelle, experience, credentials)
- orvelle.html, markets.html, assurance.html, advisory.html: live tools linked from the main page
- Excel models, decks, reports and the tailored resume (Tarana_Bansal_Resume.pdf) that the pages link to
- og-card.png: the preview image shown when the link is shared

Data in the live tools is illustrative or synthetic unless stated otherwise.
